# Приложение для анализа банковских операций

Проект для анализа транзакций из Excel-файла с генерацией JSON-данных для веб-страниц, сервисов и отчётов.

## Структура проекта
```
.
├── src/
│ ├── init.py
│ ├── main.py # точка входа
│ ├── utils.py # вспомогательные функции (API, фильтрация)
│ ├── views.py # функции для веб-страниц (Главная, События)
│ ├── services.py # сервисы (поиск, кешбэк, инвесткопилка)
│ └── reports.py # отчёты (траты по категориям, дням недели)
├── data/
│ └── operations.xlsx # файл с транзакциями
├── tests/
│ ├── init.py
│ ├── test_utils.py
│ ├── test_views.py
│ ├── test_services.py
│ └── test_reports.py
├── .env_template # шаблон для переменных окружения
├── .flake8 # конфигурация Flake8
├── .gitignore
├── pyproject.toml # зависимости и настройки инструментов
├── poetry.lock
├── user_settings.json # настройки валют и акций
└── README.md
```

## Установка и запуск

**Клонирование и переход в директорию:**
```
git clone <URL-репозитория>
cd <название-папки>
```
**Установка зависимостей:**
```
pip install -r requirements.txt
```
**Настройка переменных окружения:**
* Скопируйте `.env_template` в `.env`

* Заполните переменные (API-ключи для курсов валют и акций)

**Запуск основного модуля:**
```
python src/main.py
```
**Запуск тестов:**
```
pytest
```
**Проверка покрытия тестами:**
```
pytest --cov=src --cov-report=html
```
Отчёт будет доступен в `htmlcov/index.html.`

## Функциональности

### Базовые функции (модуль utils.py)

* read_excel — чтение Excel-файла с транзакциями
* filter_by_date — фильтрация транзакций по дате
* get_currency_rates — получение курсов валют через API
* get_stock_prices — получение цен акций через API

### Веб-страницы (модуль `views.py`)

**Главная страница (`main_page`)**

Принимает дату в формате `YYYY-MM-DD HH:MM:SS`
Возвращает `JSON` с:
* Приветствием в зависимости от времени суток
* Расходами и кешбэком по каждой карте (1 рубль на каждые 100 рублей)
* Топ-5 транзакций по сумме
* Курсами валют из настроек пользователя
* Ценами акций S&P 500 из настроек пользователя

### Сервисы (модуль `services.py`)

**Простой поиск (`simple_search`)**

* Поиск транзакций по ключевому слову в описании или категории
* Регистронезависимый поиск
* Возвращает список найденных транзакций

### Отчёты (модуль `reports.py`)
**Декоратор `report_to_file`**

* Автоматически сохраняет результат функции-отчёта в JSON-файл
* Может принимать имя файла или генерировать его автоматически (формат: `report_YYYYMMDD_HHMMSS.json`)

**Траты по категории (`spending_by_category`)**

* Анализ расходов по заданной категории за последние 3 месяца
* Учитываются только расходы (отрицательные суммы)
* Возвращает отфильтрованный DataFrame с транзакциями

## Инструменты и конфигурация

* `Poetry / pip` — управление зависимостями
* `Flake8` — линтинг (максимальная длина строки — 119 символов)
* `Black` — форматирование кода
* `isort` — сортировка импортов
* `mypy` — проверка типов
* `pytest` — тестирование с Mock, фикстурами и параметризацией
* `pytest-cov` — оценка покрытия кода тестами
